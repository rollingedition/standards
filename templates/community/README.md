# Rolling Edition's community files

GitHub uses these files for every repository in the Rolling Edition organization that has none of its own.

| File | What it's for |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to report an error in a book, how to fix one with a pull request, and how a change merges |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | The Contributor Covenant 2.1, and where to report conduct |
| [SECURITY.md](SECURITY.md) | How to report a security problem privately |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | The forms for reporting an error and asking a question |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | What every pull request is asked |
| [`profile/README.md`](profile/README.md) | The organization's page on GitHub |

The books are at [rollingedition.com]({site}). These files are generated from templates in the [standards]({standards}) repository; to suggest a change, open an issue there.
