# Rolling Edition

Free technical books that AI drafts, people verify, and an automated pipeline keeps current as libraries change.

- **Read the books** at [rollingedition.com]({site}). Every edition shows the date its examples last passed, how many of them pass and what changed.
- **Every book is a repository here,** named `book-…`. Found a mistake? Report it on the book's repository, or fix it with a pull request: [how to contribute]({contributing}).
- **[standards]({standards})** holds the checks every book runs, the writing standards, and the code that draws each cover and edition code.

Written with AI. Verified by people.
