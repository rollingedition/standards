# Security

If you find a security problem in a book repository, such as an example or a workflow that could leak a secret or run untrusted code, report it privately: open the repository's **Security** tab and choose **Report a vulnerability**. If the tab doesn't offer it, email {security_contact}. Please don't open a public issue for it.

Examples run in a sandbox with the network blocked and no secrets, and checks on a pull request from a first-time contributor wait for approval before they run.
